Project 01

Revenue by Product and Branch

Excel · PivotTable · PivotChart

Screenshot of the PivotTable and PivotChart created in Excel.

The task was to compare revenue generated by different products across several branches. I organized the sales information in a PivotTable and used a column PivotChart to display the results. The chart makes it easier to compare product revenue between branches and identify products with higher sales.

Project 02

Revenue Calculations with SUMIF

Excel · SUMIF · Data analysis

Screenshot showing the sales data and SUMIF calculation.

The task involved working with sales records containing product codes, quantities, prices, and revenue. I used the SUMIF function to add revenue values that match a selected product code, using the cleaned product-code column as the criteria range. This demonstrates how a formula can summarize transaction data by category without adding the values manually.
